# DJ R4UL DO HELIPA — site oficial

Site estático pronto para publicar no GitHub Pages. Não usa framework, instalação de dependências nem processo de compilação.

## Publicar no GitHub Pages

1. Baixe e extraia o arquivo `site-dj-r4ul-do-helipa.zip`.
2. No GitHub, crie um repositório novo (por exemplo, `r4uldohelipa-site`).
3. Entre no repositório e escolha **Add file → Upload files**.
4. Envie o conteúdo desta pasta, mantendo `index.html`, `styles.css`, `script.js`, `assets/` e `.nojekyll` na raiz do repositório.
5. Clique em **Commit changes**.
6. Abra **Settings → Pages**.
7. Em **Build and deployment**, selecione **Deploy from a branch**; em **Branch**, escolha `main` e `/ (root)`; salve.
8. O GitHub exibirá o endereço público do site nessa mesma tela após a publicação.

## O que está incluído

- Página inicial e apresentação artística.
- Seção de agenda e histórico de outubro de 2026.
- Arquivo de fotos e flyers, com visualização ampliada.
- Press Kit, release artístico e portfólio em PDF.
- Contato por e-mail e link para Instagram.
- Informações de booking e estrutura técnica.

## Atualizar o site

- **Agenda:** abra `index.html` e procure por `Próximas datas` e `HISTÓRICO RECENTE`. Atualize os textos e datas dos eventos nessa seção. Quando houver uma data confirmada, substitua a mensagem de agenda aberta pela informação do evento.
- **Instagram:** procure por `instagram.com/r4uldohelipa` em `index.html` para alterar o endereço do perfil, caso necessário.
- **E-mail de booking:** procure por `contato.badgarden@gmail.com` em `index.html`.
- **Fotos e flyers:** envie os novos arquivos para `assets/photos/` ou `assets/flyers/` e atualize o caminho da imagem correspondente em `index.html`.
- **PDFs:** substitua os arquivos dentro de `assets/docs/`, mantendo os nomes atuais, ou ajuste os links dos cards de materiais em `index.html`.
